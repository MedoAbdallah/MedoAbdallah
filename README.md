### 👋 About Me

I'm a **Flutter developer** focused on building clean, scalable, cross-platform mobile applications — from design to deployment.

I work across the full pipeline:
- Designing UI in **Figma**
- Testing APIs with **Postman**
- Building with **Android Studio**
- Integrating **Firebase** and **REST APIs** for the backend

I've also collaborated on several team projects, contributing features to production-style apps in **tracking**, **fitness**, and **exam platforms**.
