### 👋 About Me
I'm a Flutter developer focused on building clean, cross-platform mobile apps 
from design to deployment. I work across the full pipeline — designing UI in 
Figma, testing APIs with Postman, and building in Android Studio — with 
Firebase and REST APIs for the backend layer.

I've also collaborated on several team projects, contributing specific 
features to production-style apps (tracking, fitness, and exam platforms).
